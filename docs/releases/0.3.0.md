# 0.3.0 文档与源码树基线

日期：2026-10-21

## 范围

0.3.0 是版本、文档、打包和仓库整理基线。它重构设备接入分层，新增只读候选 BootPlan 和受限表单 POST/多步 HTTP 协议，并完成 GET/HEAD 崩溃路线的 DIR-825 真实验证；权威运行时和架构范围未扩展。

## 变更

- `pyproject.toml` 与 `repair_tool.__version__` 统一为 0.3.0。
- 顶层 README 重构为当前产品指南，不再作为累积发布笔记。
- `docs/ARCHITECTURE.md` 说明控制器、源码流程、固件路线 A、证据模型、注册表、验证和扩展边界。
- `docs/OPERATIONS.md` 说明安装、配置、路线 A、受控 FirmAE wrapper、更新、打包、隐私和故障处理。
- `docs/CHANGELOG.md` 记录 0.2.0 之前简史、每个 0.2.x 版本和本版变更。
- `docs/SUPPORTED_FIRMWARE.md` 建立已验证固件/CVE 矩阵，登记 CVE-2025-6291 栈溢出和 CVE-2024-57595 命令注入的 DIR-825 2.03 证据与解释边界。
- `cases/README.md` 建立固件案例卡规范；CVE-2025-6291 和 CVE-2024-57595 均登记为 `validated`。CVE-2024-57595 保留六步声明式 PoC、wrapper 补丁源码/对象/候选、真实 run 报告和独立验证证据。
- `docs/ROADMAP.md` 明确最终目标是绝大多数固件通用的大模型自动漏洞修复；当前真实闭环覆盖 DIR-825 B 2.03 / MIPS32BE / `sbin/httpd` 的 GET/HEAD 栈溢出与受限表单多步命令注入，并给出路线 A/B/C 与 P1–P6 计划。
- 路线 A 向导界面改为中文分步面板：菜单标注推荐项和风险项，回车执行推荐操作，inspect 完成状态可持久化；真实模型外发确认只接受大写 `YES`，不再显示 `Y/N`。
- 固件源码分层重构：`firmware/session/` 承载通用进程身份、清理和 HTTP 隧道；`firmware/runtimes/` 承载运行时装载事实；`firmware/profiles/` 承载封闭设备注册表和 DIR-825 profile；删除误导性的 `firmware/adapters/dir825/` 目录。
- 新增 `repair boot-plan` 只读探测命令，为新设备生成 candidate-only 目标、init、架构和 launch mode 线索。
- 新增受限表单 POST / Cookie / 多步协议和命令注入 marker 验收，接入 doctor、reproduce、fixed checks、generated tests 和 verify；默认 GET/HEAD 崩溃路线保持原编码与语义。
- 修正 0.3.0 打包测试的旧 README 断言和夹具，补充首次安装 checksum 校验说明，并统一 `*.command` 配置为非空 argv 数组。
- 发布包纳入 `docs/` 中的精选文档和 `cases/` 中的案例说明、PoC、模板、修复源码与脱敏结果。
- 过程性旧文档、历史 ZIP、实验、历史修复结果、临时文件和缓存移动到被忽略的本机归档目录。

## 明确非目标

0.3.0 不声称 Greenhouse 兼容、额外固件架构、HTTPS/非 80 端口协议、任意固件通用化或物理设备验证。受限表单/多步协议的真实验证仅覆盖 CVE-2024-57595 的声明式流程和 marker 场景。
